# يلا نلعب — Yalla Nelaab

A sit-together word game for a toddler learning Egyptian Arabic. A parent plays it with the child on an iPad or iPhone; the screen helps, the parent leads.

- Runs in Safari, no install: open the page, then Share → Add to Home Screen. Works offline after the first visit.
- The child's screen has nothing to press but the game. Parent controls: hold the faint ⚙️ corner for 2 seconds, then tap "افتح للأهل". To move on after a word, press anywhere for 1 second.
- Nothing about the child leaves the device. The parent's voice recordings and the word progress stay in the browser on that device. The microphone measures only how hard the child blows; it never records the child.

## Run and test

```sh
npm run serve      # http://127.0.0.1:8770
npm test           # unit tests (Node 22+, no dependencies)
npm run e2e        # the game in headless Chrome
```

Pictures are the device's own emoji.
